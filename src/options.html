Website access

Checking website access…

Firefox will ask for HTTP/HTTPS website access. Detection checks only the page's display mode and loading state; it does not read or transmit page content. Detected app windows are excluded. An app whose mode cannot be read may still participate in grouping.

Grouping

Checking grouping state…

New enabled-container tabs group in regular or unknown windows. Initial tabs of newly opened windows stay in place to protect app launches. Grouping these explicitly requires a regular-browser display-mode signal.

Containers

Choose which containers group automatically. Default-container tabs stay in place. Changing these choices does not rearrange existing tabs.
