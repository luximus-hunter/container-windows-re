Website access

Firefox doesn’t tell extensions whether a page is open in an app window or a regular browser tab. With permission to access HTTP and HTTPS sites, this extension can check each page’s display mode and loading state to detect app windows. It never collects or sends page content.

Checking website access…

You can manage website access anytime in the add-on’s Firefox settings.
